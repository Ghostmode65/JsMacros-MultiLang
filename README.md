# JsMacros-MultiLang
Lua, Python and Ruby all packed into one.


[LuaJ](https://github.com/luaj/luaj): Lua 5.1 <br>
[Luava](https://github.com/KienPC1234/luava): Lua 5.4 / Luava 0.2.5 <br>
[Python](https://github.com/oracle/graalpython): 3.10.13 / GraalPy 24.0.1 <br>
[Ruby](https://github.com/jruby/jruby): 4.0.0 / JRuby 10.1.0.0 <br>

Luava can be enabled in settings, as an experimental option.<br>
GraalPy comes bundled with all its natives for all operating systems.<br>
